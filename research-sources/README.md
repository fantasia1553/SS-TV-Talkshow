# Research Sources

本目录记录节目使用的事实来源。先查看 [source-log.md](source-log.md)。

## 四类内容要分开

| 类型 | 稿件处理 |
| --- | --- |
| 可核查事实 | 用 S01 等编号关联来源，记录原文所在小节 |
| 观点或建议 | 明确说 “we suggest / could / in our view” |
| 虚构情景 | 明示为 fictional example，不当成采访 |
| 尚未核实的内容 | 标记待核实，不作为已证实事实播出 |

## 添加资料

1. 优先查原始研究、官方统计、政策原文或直接发布者；新闻可以提供线索。
2. 打开原文核对，记录机构/作者、标题、日期、链接、章节和查阅日期。
3. 写出该来源支持的具体句子，也写出它**不能**证明什么。
4. 记录脚本使用位置；删除脚本中的主张时同步更新记录。
5. 采用自己的概述；必要的短引文应加引号并标明来源。
6. 统计资料要注明年份、地域、样本或统计口径，避免混用公民、居民、非居民等类别。

官方页面能说明政策目标和活动安排，不自动证明实际效果。当前两条来源不是独立效果研究，也不能代表所有本地人与新来者的感受。若课堂要求评估成效，需要补充适当研究或可使用的真实资料。

## 参考资料页格式（暂定）

机构/作者. (页面发布日期或更新年份). *标题*. URL. 查阅日期：YYYY-MM-DD。

最终格式和最低来源数按老师要求调整。不要自行填写无法确认的发布日期；可写“未标明”。

## 采访或课堂观察（如采用）

记录收集时间、提问方式、对象范围、是否获准引用及匿名化方式。小样本只能描述该次反馈；不要推论整个新加坡社会。未开展的调查不填写结果，公开仓库不存放私人联络信息或未经许可的原始记录。
