## 选题依据与草案边界

此前讨论过新加坡 diversity 课堂 talk show，包括本地人与外国人的融合，以及 “English and Mother Tongues: Can Singapore Keep a Balance?”。本版本暂用前者演示资料组织；这不代表小组已经选定主题。核心方向是 cultural and nationality diversity，关注学校生活中的参与机会和归属感。

- 为便于起稿，暂设 **4 个表演角色、8 分钟节目框架、英文对白、中文制作说明**；都不是已知课堂要求。
- 示例人物与经历均为虚构，不是组员经历、真实采访或研究结果。
- “新来者”是便于讨论的宽泛称呼，不等同于任何单一国籍或移民身份。公民、永久居民、国际学生等应按实际来源区分；不将种族、国籍与文化混为一谈。
- 已有其他课程材料是否适用于本项目仍待核实；未将其他展示的时长、稿件或要求当成本节目要求。

## 一轮修改的做法

1. 先补老师要求和已存在的稿件，再确认主题与人数。
2. 按大纲修改脚本；新增事实先写入来源记录，脚本注明来源编号。
3. 按角色读一遍，记录实际时长、难读句和不自然的转场。
4. 复制 revision-notes/TEMPLATE.md，保存为 `YYYY-MM-DD-简短说明.md`。
5. 保存清楚的提交说明，例如 `docs: shorten opening and verify source S01`；同一时间避免多人直接改同一个文件。
